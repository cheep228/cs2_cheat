# Лимит трафика (Android)

Приложение считает трафик в фоне и отключает интернет всему, что его «жрёт», по правилам,
которые задаются отдельно для каждой сети.

## Что умеет

- **Главная галочка «Ограничивать трафик»**: если снята, ничего не блокируется, трафик только считается.
  Её же можно переключить прямо из уведомления.
- **Профили для сетей**: конкретный Wi‑Fi (по имени SSID), любой Wi‑Fi, мобильная сеть или любая сеть.
  У каждого профиля своя галочка «Ограничивать трафик в этой сети».
  Выбирается самый точный профиль: Wi‑Fi с этим именем → любой Wi‑Fi → мобильная → любая.
- **Лимиты**: в минуту, в час, в день и максимум всего (до ручного сброса), в МБ.
  Когда любой лимит исчерпан, блокируется **весь** трафик, кроме приложений «Всегда разрешать».
  Минутный, часовой и дневной лимиты снимаются сами в начале следующей минуты, часа или дня.
- **Правила приложений** (свои для каждой сети):
  - *Блокировать всегда*: приложение не получает интернет в этой сети;
  - *Всегда разрешать*: не блокируется никогда, даже после исчерпания лимита;
  - *Обычный* + **дневной лимит приложения**: блокируется, когда израсходует свой лимит за день.
- **Блокировка фонового трафика**: интернет получает только приложение, открытое на экране.
  Фоновые загрузки, автообновления и синхронизация отключаются; при выключенном экране блокируется всё.
- **Работа в фоне**: постоянная служба с уведомлением показывает скорость и расход, сама запускается
  после перезагрузки и предупреждает, когда лимит исчерпан.

## Как это работает

- Трафик считается раз в секунду по системным счётчикам `TrafficStats` и записывается на профиль текущей сети.
- Блокировка сделана через локальный `VpnService`: в VPN направляются только приложения, которые нужно
  заблокировать, и их пакеты отбрасываются на телефоне. **Никакого сервера нет, трафик никуда не уходит.**
  Остальные приложения работают напрямую, без VPN. Root не нужен.
- **Режим root** (галочка «Блокировать через root (iptables)»): вместо VPN приложение добавляет правила
  `iptables`/`ip6tables` по UID приложений в собственную цепочку `tlimit` (подключена к `OUTPUT`).
  Плюсы: VPN-слот свободен, поэтому можно пользоваться своим VPN, а заблокированные приложения сразу
  получают отказ, а не ждут таймаута. При выключении режима или остановке службы правила удаляются.
  Если `su` не сработал, приложение показывает ошибку и пробует снова раз в 30 секунд.
- Расход по приложениям и открытое приложение берутся из `NetworkStatsManager` и `UsageStatsManager`.

## Разрешения

| Разрешение | Зачем |
|---|---|
| VPN | блокировать приложения |
| Уведомления | расход в шторке и предупреждения |
| Геолокация (+ «Разрешить всегда») | без неё Android не сообщает имя Wi‑Fi сети |
| Доступ к истории использования | расход по приложениям, лимиты приложений, блокировка фона |
| Без оптимизации батареи | чтобы система не останавливала службу |

Приложение само показывает, каких разрешений не хватает, с кнопками, которые их выдают.

## Ограничения

- Одновременно может работать только один VPN. Если включить другой VPN, блокировка остановится,
  но подсчёт трафика продолжится.
- Это ограничение по **объёму**, а не по скорости: после исчерпания лимита трафик отключается до сброса окна.
- Если заблокировать всё, push-уведомления (Google Play Services, `com.google.android.gms`) тоже пропадут.
  Добавьте их в «Всегда разрешать», если они нужны.
- Расход по приложениям Android обновляет с небольшой задержкой, поэтому дневной лимит приложения
  может сработать чуть позже.
- Нужен Android 10 или новее.

## Сборка

Нужны JDK 17+ и Android SDK (platform 35):

```
cd TrafficLimiter
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # юнит-тесты логики лимитов
```

Release-APK подписан debug-ключом, поэтому ставится сразу. Для публикации подпишите своим ключом.
