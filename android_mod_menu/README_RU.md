# NoomiCloneX — плавающее мод-меню 🎃

Чит на **офлайн** Unity-игру `NoomiCloneX` (пакет `com.JamesWest.NoomiClone`, v1.7).
Плавающая кнопка-тыква поверх игры → меню: **деньги**, **перехваты**, **Fly**.

---

## Что я выяснил про игру (важно)

| Что | Значение |
|---|---|
| Движок | **Unity 6 (6000.6.0f1), IL2CPP** |
| Архитектура | только `arm64-v8a` |
| Защита | **NXGATE** — анти-чит/анти-тамперинг (`libge32c849974168bd8.so` + `g5924ea53771c0357.bin`) |

**Почему НЕ пересобираем APK.** Из-за NXGATE пересобранный/переподписанный APK
почти наверняка задетектится как модифицированный и игра не запустится/закроется.
Поэтому меню делается **через Frida в рантайме** — сам APK не трогаем, всё цепляется
к уже запущенному процессу. У тебя есть root (SukiSU/KernelSU) — это всё, что нужно.

`libil2cpp.so` экспортирует все стандартные `il2cpp_*` функции → рантайм-доступ к
классам/полям игры работает, несмотря на обфускацию метаданных.

---

## Что нужно

1. **Root** на телефоне — есть (SukiSU). ✅
2. **frida-server** на телефоне (кладём в `/data/local/tmp`, запускаем от root).
3. **frida-tools** — откуда запускать скрипт. Два варианта:
   - **A. ПК по USB** (проще и надёжнее): нужен `adb` + `pip install frida-tools`.
   - **B. Только телефон**: приложение **Termux** → `pkg install python && pip install frida-tools`.

> Версия frida-server и frida-tools должна совпадать (у нас **17.25.2**).

---

## Установка по шагам

### Шаг 1. frida-server на телефон
На ПК или в Termux:
```bash
bash get_frida_server.sh 17.25.2
```
Скрипт скачает и распакует `frida-server`. Дальше залей его на телефон и запусти от root:

**Вариант A (ПК + adb):**
```bash
adb push frida-server /data/local/tmp/fs
adb shell "su -c 'chmod 755 /data/local/tmp/fs; /data/local/tmp/fs &'"
```
**Вариант B (Termux на телефоне):**
```bash
cp frida-server $HOME/fs
su -c 'cp '$HOME'/fs /data/local/tmp/fs; chmod 755 /data/local/tmp/fs; /data/local/tmp/fs &'
```
Проверка, что сервер поднялся: `frida-ps -U` — должен показать список процессов.

### Шаг 2. Установить frida-tools (на той же машине, откуда запускаешь)
```bash
pip install frida-tools==1.0.2    # подтянет frida 17.25.x
frida --version                   # должно быть 17.25.x
```

### Шаг 3. Запуск меню
Сначала **запусти игру руками**, зайди в геймплей, потом:
```bash
bash run.sh attach
```
Если `attach` не цепляется по имени — запусти вместе с игрой:
```bash
bash run.sh spawn
```
Через пару секунд в левом-верхнем углу появится **🎃**.
Тыкни — раскроется меню. Тыкву можно таскать пальцем.

## Меню

- **Деньги** — ввести число → `Деньги`.
- **Перехваты** — ввести число → `Перехваты`.
- **Fly: OFF/ON** — анти-гравитация (персонаж «парит», не падает).
- **Поиск** — найти поле по имени (вывод в консоль frida).
- **Dump C#** — выгрузить структуру игры в файл.

> ⚠️ Пока меню в **эвристическом режиме**: кнопки «Деньги»/«Перехваты» меняют *все*
> числовые поля с похожими именами (money/coin/grip/…). Это может задеть лишнее.
> Чтобы било точно в цель — нужен дамп (ниже).

---

## Донастройка под точные поля (один заход)

1. Запусти разведку:
   ```bash
   bash run.sh dump
   ```
   В консоли сразу напечатаются **кандидаты** на деньги/перехваты/полёт.
2. Полный дамп сохранится в `/data/data/com.JamesWest.NoomiClone/noomi_dump.cs`.
   Забери его рутом:
   ```bash
   su -c "cp /data/data/com.JamesWest.NoomiClone/noomi_dump.cs /sdcard/noomi_dump.cs"
   ```
3. **Пришли мне этот файл** (или вывод кандидатов из консоли) — я впишу точные
   `class/field` в `CONFIG` внутри `src/menu.ts`, пересоберу, и кнопки будут
   менять ровно деньги и перехваты. Тогда же сделаю **нормальный направленный полёт**,
   когда увижу класс контроллера персонажа.

## Если NXGATE мешает (игра крашится/закрывается при frida)

Варианты обхода (по возрастанию сложности) — напишу точнее, если упрёмся:
- запускать frida-server на **нестандартном порту** и переименованным бинарником
  (`/data/local/tmp/abc` вместо `frida-server`), цепляться `frida -H 127.0.0.1:PORT`;
- **KernelSU/SukiSU hide** на процесс игры;
- встроить **frida-gadget** через LSPatch (это уже модификация APK — крайний случай).
